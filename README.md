# 终点站不存在 · The Absent Terminus

Godot 4 第一人称 3D 列车密室逃脱原型。你在雪夜复古列车上醒来，通过同一空间的三个年代寻找广播零件，找回被遗忘的终点站。

## 运行

使用 **Godot 4.7** 打开 `project.godot`，等待资源导入，按 **F5**。主场景为 `scenes/main.tscn`。已在 macOS / Apple Silicon / Godot 4.7.2 上验证，其他平台尚未实机验证。

默认使用 Forward+，含体积雾、环境遮蔽、动态阴影与抗锯齿。Esc 暂停菜单可以切换“电影 / 流畅”画质并调整音量。

## 新玩法：引导探索

**跟随目标找线索 → 到机关使用道具 → 解锁下一个区域 → 决定终点。**

- 首次进入会说明玩法；旧存档首次载入也会介绍新的规则。
- 左下角显示当前唯一目标，金色菱形指向对应物件或必经出口。H 随时查看当前步骤的具体提示。
- 到车厢端门或隐藏房间的检修钟前按 E，明确选择“出发之夜 / 停电时刻 / 多年以后”；切换后留在原位。
- 连杆和阀门各操作一次，效果会持续到其他年代。
- 收集黄铜钥匙、车顶继电器、乘务员徽章，到广播柜一次安装。柜内会列出缺失物品和位置。
- 道具在对应场景使用，接线、调谐与车票打孔自动完成。
- 选错站名可以立即重试；提前碰到封闭通道只提示原因。乘务员和环境异象推进故事，探索进度始终保留。
- Tab 手记保存已发现线索、物品清单和当前目标。
- 三份事故记录属于可选调查。广播恢复后，选择“继续寻找事故记录”即可获得逐步引导，解锁第三种结局。

三个年代各有用途：出发之夜有电，可以操作维修连杆和广播；停电时刻能转动泄压阀、进入记忆空间；多年以后能从腐朽处找到钥匙、继电器和事故记录。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 环顾 |
| Shift | 快走 |
| E | 查看、拾取、打开机关操作面板；收起阅读界面 |
| F | 手电筒 |
| Tab | 乘客手记 |
| H | 玩法与当前步骤提示 |
| Esc | 暂停或收起界面 |
| F11 | 切换全屏 |

进度自动保存。读档时回到当前年代的主车厢安全点，已修机关和随身物品保留。旧 v1 / v2 存档会自动转为新的永久修复状态，并写入独立的 v3 存档，旧文件保留。

## 场景与故事

主车厢可探索软包座椅、木饰面、行李架、茶杯、窗帘、结霜车窗和夜间雪景，连接维修夹层、车顶检修舱与记忆空间。失踪乘务员通过广播、脚步、倒影和检查记录出现。故事有离站、接班、公开事故记录三个结局。

探索时会间歇出现灯光衰弱、身后脚步、凝视后消散的窗边人影，以及短暂的近距离突脸。突脸在找到 07 席照片后进入事件轮换，先压暗灯光，再用约一秒的人脸逼近和短促音效制造惊吓；两次突脸至少间隔 110 秒有效游玩时间。阅读、暂停、年代切换和结局会收起效果，剧情广播优先。所有声音服从暂停菜单的总音量，异象不改变物品、存档或解谜进度。

场景以程序化模型搭建，尚未加入专业角色动画、完整配音或自由旋转的 3D 物品查看器。新模式实际游玩时长需经真人试玩确认。

## 项目结构

- `scripts/game.gd`：章节目标、交互、永久修复、年代选择、故事事件、存档和结局。
- `scripts/train_world.gd`：程序化列车、隐藏空间、年代差异、环境异象与站台。
- `scripts/temporal_object.gd`：跨年代物件状态，兼容旧锚点数据。
- `scripts/player.gd`：第一人称移动、碰撞与视线检测。
- `scripts/hud.gd`：引导、目标标记、手记与中文菜单。
- `scripts/interactable.gd`：交互区域。
- `scripts/horror_director.gd`：恐怖事件节奏、空间音效、灯光恢复与突脸。
- `assets/`、`shaders/`：程序化纹理、音效、中文字体与玻璃 / 暗角效果。
- `tools/generate_assets.py`：用 Python 3 标准库重建原创纹理与音效。
- `tools/smoke_test.gd`：真实主场景的流程集成测试。
- `tools/generate_horror_audio.py`：生成四段原创恐怖氛围与惊吓音效。
- `tools/check_horror.gd`：恐怖事件、暂停恢复、冷却与进度保留检查。
- `artifacts/`：实际游戏渲染截图。

场景在运行时生成；要在编辑器检查生成节点，运行后切换到“远程”场景树。

## 开发验证

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tools/smoke_test.gd
godot --headless --path . --script tools/check_horror.gd
godot --path . --script tools/check_horror.gd -- --capture-horror
godot --path . -- --capture
```

集成测试通过实际玩家射线和 E 输入触发关键物件，通过界面按钮完成选择；覆盖新手引导、年代选择、上下文修复、错误操作、三个结局、可选调查、旧存档迁移与重新开始。测试使用独立临时存档。

`--capture-horror` 使用真实渲染器，将灯光、人影和突脸截图保存到 `artifacts/horror/`；该检查不会修改玩家存档。

截图模式导出标题、玩法说明、三个年代、年代选择、广播零件清单、手记、站名选择、结局选择和站台，随后退出；不会写入玩家旅程存档。

新存档：`user://journey_v3.cfg`。兼容读取 `journey_v2.cfg`、`journey_v1.cfg`。设置：`user://settings.cfg`。macOS 通常位于 `~/Library/Application Support/Godot/app_userdata/终点站不存在 · The Absent Terminus/`。
